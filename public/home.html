Developer ecosystem

Build it once. Reach every group.

Write a plugin, push a release tag to GitHub and send it for review. When it passes, it is signed and published to the marketplace for bot owners to install.

Open Developer CentreRead the guide
  1. 1
    Sign in with GitHub

    No new password. Your repository stays yours.

  2. 2
    Send a release tag

    Or let a GitHub webhook send each new release for you.

  3. 3
    Automatic checks, then review

    The manifest, permissions and code are checked before a person looks.

  4. 4
    Signed and published

    Approved releases are signed with the TurboFex key and appear in the store.

Automation

What a plugin can do

Plugins add commands and reactions to your bot. Each one only gets the powers its owner approves.

Commands

New commands that use your normal prefix, with their own help text.

Events

React to new messages, members joining and members leaving.

Pictures and files

Send and convert media, within safe size limits.

Group tools

Group management, only for plugins you allow and bots that are admins.

Options

Owners change a plugin's settings with one command.

Private storage

Each plugin keeps its own notes, apart from every other plugin.

Security and reliability

Safe by design, not by promise

Signed store

Every published plugin is signed. A bot refuses anything that was changed.

Sandboxed code

Plugins run in a sealed sandbox, away from your bot's files and keys.

Owner approves powers

A plugin cannot use a power its owner did not allow.

Reviewed first

Nothing reaches the store without checks and a human review.
