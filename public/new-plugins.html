How to install

  1. 1
    Install

    Send .plugin install and the plugin name. The bot downloads it, checks it and shows what it asks for.

  2. 2
    Confirm

    Read the list. Then send .plugin confirm with the code the bot gives you.

Only the bot owner can install or remove plugins. Some plugins come with the bot and cannot be removed. Switch a plugin off with .plugin disable and its name. If you changed the command symbol, use yours.
