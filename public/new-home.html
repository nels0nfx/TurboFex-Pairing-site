Questions

What is TurboFex?

A WhatsApp bot that helps you run groups and gives chats tools, games and fun. You host it yourself.

Is it safe for my WhatsApp?

TurboFex uses an unofficial WhatsApp Web connection, not the official WhatsApp Business Platform. WhatsApp may restrict or ban numbers that use it, so use a spare number and consider the risk to the account.

Where can I run it?

Anywhere Node.js 20 or newer runs: a phone with Termux, a server, Docker, a hosting panel, a web host, Windows or Mac.

How do I link my WhatsApp?

Use the Pair page. Enter your number for a pairing code, or scan a QR code. You get a session ID for the bot.

Can I add features?

Yes. Install plugins from the marketplace, or write your own with the plugin guide.
