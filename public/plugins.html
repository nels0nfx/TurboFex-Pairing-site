Installing

Two steps, on your bot

  1. 1
    Install

    Send .plugin install and the plugin name. Your bot downloads it, checks it and shows exactly what it asks for. (Use your own command symbol if you changed it.)

  2. 2
    Confirm

    Read the list, then send .plugin confirm with the code the bot gives you.

Only the owner of the bot can install or remove plugins. Plugins are always ready to use. Some plugins come with the bot and cannot be removed. You can switch a plugin off with .plugin disable and its name, or in a single group.
