How to install a plugin

  1. Send .plugin on to your bot once. Plugins are off until you do. (Use your own command symbol if you changed it.)
  2. Send .plugin install followed by the plugin name. Your bot downloads it, checks it and shows exactly what it asks for.
  3. Read the list, then send .plugin confirm with the code the bot gives you.

Only the owner of the bot can install or remove plugins. .plugin off removes every plugin command at once, and you can switch a plugin off in a single group.
