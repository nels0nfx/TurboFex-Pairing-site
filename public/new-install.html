Install

Install TurboFex

Get the bot, link your WhatsApp, start it.

Before you start

TurboFex uses an unofficial WhatsApp Web connection, not the official WhatsApp Business Platform. WhatsApp may restrict or ban numbers that use it. Use a spare number and consider the risk to the account.

Three steps

  1. 1
    Get the bot

    Download the hosting ZIP from Releases. Not the green Code button.

    ReleasesHosting guides
  2. 2
    Link your WhatsApp

    Pair on this site and get a session ID. It works once and expires after 5 minutes.

    Open Pair
  3. 3
    Paste it and start

    Put the ID after SESSION_ID= in session_id.txt, start the bot, then send .ping in WhatsApp.

Where to run it

Needs Node.js 20 or newer. Pick one.

Termux
pkg update && pkg upgrade
pkg install nodejs-lts git ffmpeg unzip nano
termux-setup-storage
unzip ~/storage/downloads/TurboFex-hosting-*.zip -d ~/TurboFex
cd ~/TurboFex
npm install
nano session_id.txt
npm start

Install Termux from F-Droid, not the Play Store. Paste your session ID after SESSION_ID= in session_id.txt.

VPS
sudo apt update && sudo apt install -y git ffmpeg unzip curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
unzip TurboFex-hosting-*.zip -d ~/TurboFex && cd ~/TurboFex && npm install
nano session_id.txt
npm start

Keep it running with pm2 or systemd. Both are in the hosting guides.

Docker
cd TurboFex
echo "SESSION_ID=TFX-XXXX-XXXX-XXXX" > .env
docker compose up -d --build
docker compose logs -f

Run these in the folder you unpacked the hosting ZIP into. Login and settings are saved in the data, session and accounts folders.

Panel
  1. 1Create a server with a Node.js 20 or newer egg.
  2. 2Upload the hosting ZIP and unzip it so index.js is in the main folder.
  3. 3Set the startup command to npm start.
  4. 4Put the session ID in session_id.txt, or in the SESSION_ID variable, and start the server.
Web host
Build command:  npm install
Start command:  npm start
Variable:       SESSION_ID = your session ID

Use a plan with a persistent disk for the data and session folders. Many web hosts wipe the disk on restart, and the bot then needs a new session ID.

Windows / Mac
npm install
npm start

Install Node.js (LTS) and Git first, unpack the hosting ZIP and open a terminal in its folder. Paste the session ID in session_id.txt before you start.
