How it works

  1. 1
    Write it

    Follow the Docs. Keep it in a public GitHub repository with a turbofex-plugin.json file. Try it in the Playground.

  2. 2
    Tag a release

    Make a release tag on GitHub. Sign in here and send the repository address and the tag.

  3. 3
    Checks and review

    The site checks the plugin is well formed. Then a person reads it. We aim to answer within 14 days.

  4. 4
    Signed and published

    If approved, it is signed and added to the store. Bot owners install it with one command.

Rules

  • Plugins are free. Paid plugins are not supported.
  • A plugin can only do what it lists in permissions. Ask for as little as you can: plugins that ask for a lot get read more carefully.
  • Every new version is reviewed again. Raise the version number for each release.
  • The plugin id belongs to the first developer who gets it approved.
  • Approval is not a guarantee. We can withdraw a plugin at any time, and bots stop using a withdrawn plugin.

What we keep about you

Signing in with GitHub gives us your public GitHub number and username. We do not ask for your email address or any permission on your account, and we do not keep the GitHub access token. We keep your submissions, the code you sent and the review notes.

    Send a plugin

    Point us at a release tag in your public repository. We copy the code now, check it, then a person reads it.

    It must be public and belong to your own GitHub account.

    The tag of the release you want reviewed. The code is copied now, so changing the tag later does not change what we read.

      Before you send

      • Your repository is public and has a turbofex-plugin.json file.
      • You made a release tag and raised the version number.
      • You tried the plugin in the Playground.
      • It asks only for the permissions it needs.

      Send new releases automatically

      Optional. List a repository here and tell GitHub to ping us. Every new release tag is then sent for review by itself. You still choose the tag. The plugin is copied at that tag and checked like a manual send.

      Connect it on GitHub

      1. 1
        Press “Show my webhook details” below.
      2. 2
        On GitHub open your repository, then Settings, Webhooks, Add webhook.
      3. 3
        Paste the address into “Payload URL”. Set “Content type” to application/json. Paste the secret into “Secret”.
      4. 4
        Choose “Let me select individual events” and tick only “Releases”. Save.
      5. 5
        GitHub sends a test ping. A green tick means it is connected.
