Quick answers about linking

    

      
      
      
    

    

    

    

      How do I link my WhatsApp?
      

        
    
          
  1. Open WhatsApp on your phone.
    2. 
          
  2. Go to Linked devices. On Android tap the ⋮ menu, on iPhone open Settings.
    3. 
          
  3. Tap Link a device.
    4. 
          
  4. Choose Link with phone number instead, or scan the QR code shown here.
    5. 
          
  5. Enter the pairing code (or finish scanning) and wait for Linked successfully.
    6. 
        

      

    

    

      Pairing code or QR code, which one?
      
The pairing code is easiest when WhatsApp and this page are on the same phone. The QR code is best when you open this page on a computer or another screen and scan it with your phone. If one does not work, try the other.

    

    

      Which number do I enter?
      
The number of the WhatsApp account you want to link. Choose your country, then type the number without the country code. The page counts the digits for you and will not accept more than your country allows.

    

    

    

    

      What is the session ID?
      
A one-time ID that looks like TFX-XXXX-XXXX-XXXX. It is shown here and also sent to your WhatsApp chat. Give it to the TurboFex bot. It works once and expires after 5 minutes.

    

    

      Is it safe?
      

        
    
          
  • Never share your pairing code or session ID with anyone.
    • 
          
  • Only pair on this official TurboFex site.
    • 
          
  • In Linked devices, remove any device you do not recognise.
    • 
          
  • Your session is stored encrypted and removed after the ID is used or after 5 minutes. Read the Privacy Policy.
    • 
        

      

    

    

      What does pairing do?
      
It links your WhatsApp to your TurboFex bot as a linked device, the same way WhatsApp Web works. You can unlink it any time from Linked devices in WhatsApp.

    

    

      How do I unlink the bot?
      
Open WhatsApp, go to Linked devices, tap the TurboFex device and log out. The bot loses access right away.

    

    

    

    

      WhatsApp says “Couldn’t link device” or the code does not work
      
Check that the number and country are right, then tap Try again for a fresh code. Wait a few minutes if WhatsApp says it is limiting requests. If it still fails, switch to the QR code.

    

    

      My code expired or the QR stopped working
      
Codes and QR codes only live for a few minutes. Tap Try again on the code or QR screen to get a new one. You do not need to start over.

    

    

      I did not get the session ID in WhatsApp
      
It is also shown on this page, so copy it from here. It works once and expires 5 minutes after it was made. If it expired, link again to get a new one.

    

    

      Do I need to keep this page open?
      
Yes, until you see your session ID. If you refresh by mistake, the page takes you back to your unfinished attempt.
